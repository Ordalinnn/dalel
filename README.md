# Дәлел — аналитика учебных программ

**Оқулықты пікір емес, дәлел таңдайды.** Учебник выбирают доказательства, а не мнения.

MVP для кейса «Data-Driven Curriculum» (EdTech Hackathon by Zhambyl Hub, ноябрь 2026).
Платформа для методистов: берёт результаты тестирования школьников и отвечает на три вопроса:
что провалено, почему и что изменить.

## Что умеет

| Раздел | Что делает |
| --- | --- |
| Обзор тем | Освоение каждой темы с 95% интервалом (бутстреп по школам), фильтры город/село и язык обучения |
| Учебники | Сравнение учебников: сырые средние и с поправкой на прошлый балл, тип местности и язык |
| Тема | Диагноз причины: трудна тема, вопрос к учебнику, отстают школы или некачественное задание |
| Часы | Перераспределение часов при неизменной сумме, с причиной и уровнем уверенности |
| ИИ-разметка | Модель относит задание к теме из закрытого списка и сообщает уверенность |
| Записка | Записка для методсовета на русском и казахском; каждое число сверяется с расчётом |
| Библиотека | Книги для учителя по каждой причине провала темы, с фильтром по роли (методист, завуч, учитель); на странице «Тема» те же книги в блоке «Что почитать» |

**Принцип:** все числа считает проверяемый код (`core.py`). ИИ только размечает задания
и пишет текст по готовой таблице фактов.

## ИИ без ключа API

Приложение полностью работает без ключа и без интернета:

- **Разметка заданий** — собственная модель (`tagger.py`): TF-IDF по буквенным n-граммам и
  логистическая регрессия. Обучена на `data/train_items.csv` (114 заданий на русском и казахском).
  На 21 отложенном задании из `data/test_items.csv`, которых модель не видела, верно размечено 20 (95%).
  Единственная ошибка получила уверенность 0,37 и ушла бы методисту на проверку (порог 0,45).
  Выборка проверки маленькая: на реальных заданиях точность нужно измерить заново (`python tagger.py`).
- **Записка** собирается по шаблону строго из таблицы фактов, поэтому в ней не бывает выдуманных чисел.

Данные учеников при этом никуда не отправляются.

## Демо-данные синтетические

`data/` создаётся скриптом `generate_data.py`: 2 738 учеников, 60 школ, 30 заданий, 10 тем
математики 6 класса. В данные намеренно заложены эффекты, которые система должна найти:

1. Учебник А чаще выбирают городские школы: по сырым средним он лучший, после поправки — нет.
2. «Отношения и пропорции» трудны везде.
3. «Координатная плоскость» слаба только с учебником А.
4. «Линейные неравенства» провалены в 8 школах.
5. Одно задание по алгебраическим выражениям не различает сильных и слабых учеников.

Учебники названы «Учебник А/Б/В» намеренно: реальные издания на синтетических данных не сравниваются.

## Запуск

```bash
pip install -r requirements.txt
python generate_data.py      # необязательно: данные уже в data/
streamlit run app.py
python -m pytest             # тесты (нужен pytest)
```

## Ключ ИИ

Ключ необязателен. С ключом разметку и записку делает языковая модель; если API недоступен,
приложение само переключается на собственную модель и шаблон. Чтобы подключить модель, создайте `.streamlit/secrets.toml`
(в Streamlit Cloud: Settings → Secrets):

```toml
ANTHROPIC_API_KEY = "..."
# ANTHROPIC_MODEL = "claude-sonnet-5-5"
# или
# OPENAI_API_KEY = "..."
# OPENAI_MODEL = "gpt-4.1-mini"
```

Ключ никогда не кладите в репозиторий.

## Свои данные

Три файла CSV:

- `results.csv`: student_id, school_id, textbook, lang, area, prior_score, item_id, correct (0/1)
- `items.csv`: item_id, item_text, topic_code
- `plan.csv`: topic_code, topic_name, hours, prereq_count (необязательно: topic_name_kk)

Имена учеников не нужны, используйте обезличенные ключи.

## Ограничения

- Сравнение учебников основано на наблюдательных данных: это связь с поправкой на известные
  факторы, а не доказательство причины.
- Группы меньше 30 учеников не получают вывода.
- Пороги правил диагноза заданы экспертно и должны калиброваться с методистами в пилоте.
- Рекомендации по часам — гипотеза для пилота.

# Дәлел

Платформа для методистов: по результатам тестирования показывает, какие темы ученики усвоили плохо, почему, и какой учебник даёт лучший результат с учётом состава школ.

Кейс «Data-Driven Curriculum», EdTech Hackathon by Zhambyl Hub, 2026.

Демо: https://dalel-edtech.streamlit.app

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Структура

- `app.py` — интерфейс (Streamlit)
- `core.py` — расчёты: освоение тем, сравнение учебников с поправками, диагноз, часы
- `tagger.py` — модель, которая относит задание к теме программы (TF-IDF + логистическая регрессия)
- `llm.py` — записка для методсовета; ключ API необязателен
- `generate_data.py` — генератор демо-данных

## Данные

Демо-данные синтетические: 2 738 учеников, 60 школ, математика 6 класса. Учебники названы «А», «Б», «В», реальные издания не сравниваются.

Свои данные загружаются тремя CSV-файлами: результаты (`results.csv`), задания (`items.csv`) и учебный план (`plan.csv`). Нужные столбцы показаны в приложении.

## Ограничения

- Сравнение учебников показывает связь с поправкой на известные факторы, а не доказанную причину.
- Группы меньше 30 учеников не получают вывода.
- Модель разметки проверена на 21 задании, на реальных данных точность нужно измерить заново.
